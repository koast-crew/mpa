# admin-api 코드 분석 현황

## 개요

- **프로젝트**: `admin-api`
- **기술 스택**: Spring Boot 3.4.1, Spring Security, PostgreSQL, MyBatis, MapStruct, Lombok, Jasypt
- **분석 목적**: ① 운영 배포 전 코드 품질/보안 검토 ② 다른 프로젝트에서 재사용 가능한 형태로 정리
- **분석 전략**: **"실행 가능한 상태 확보" → "구조 정리" → "기능 완성"** 3단계
- **핵심 커스터마이징**: ROLE을 DB에서 관리하고 사용자 그룹에 동적으로 할당 → [동적 ROLE 구조 설명](analysis/00-동적-ROLE-구조.md)
